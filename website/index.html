For developers

Stop checking the terminal.

Start a long build, switch to something else, and the island tells you when it's done, how long it took, and whether it passed.

  • Long-running commands. Any zsh command that runs past your threshold gets a finish alert, in Terminal, iTerm, Warp or your editor.
  • AI coding agents. Claude Code and GitHub Copilot CLI show what they're doing, when they need you, and when they finish.
  • Your own scripts. A local API and the notch command put progress bars and alerts on the island from anything you write.
  • Local only. The API listens on 127.0.0.1 and needs a token, so web pages and other machines can't reach it.
# An alert, from any script
$ notch "Deploy finished" --icon checkmark.circle.fill --color green

# A live progress bar, then done
$ notch progress upload "Uploading build" 42%
$ notch done upload "Uploaded"

# Or straight to the local API
$ curl 127.0.0.1:47290/show \
    -H "Authorization: Bearer $(cat ~/.notchisland/token)" \
    --data-urlencode "title=Tests passed"

# Alerts when long zsh commands finish
$ notch install-hook

Questions

Before you download.

Does it work on a Mac without a notch?

Yes. On external displays and older MacBooks, Notch Island draws its own island at the top centre of the screen, and everything works the same.

Why isn't it on the Mac App Store?

Apps in the Mac App Store must run in a sandbox, which rules out features like reading media from your browser, terminal alerts and AI agent activity. Notch Island is signed with an Apple Developer ID and notarized by Apple, so macOS opens it without warnings.

What permissions does it ask for?

Only what the features you turn on need, and only when you first use them: Calendar and Reminders for meetings, Automation to control Music, Spotify and your browser, and Accessibility for a few optional extras. Each one is explained before macOS asks.

Will it slow down my Mac or drain the battery?

It's a small native app. While the island is closed it doesn't redraw, and background checks are spaced out. Battery saver reduces them further.

Which AI agents does it support?

Claude Code and GitHub Copilot CLI work out of the box once you turn on the Island API in Settings. Anything else can report through the notch command or the local API.

Is it really free? What's the catch?

No catch. There's no account, no ads and nothing is collected about you. It's a side project made because the notch deserved better.

How do I update it?

From version 0.9.1, Notch Island checks for a new version once a day and asks before installing it. You can also choose Check for Updates from its menu bar icon, or turn on automatic installs in Settings ▸ General. On 0.9.0? Download the latest version here once.
