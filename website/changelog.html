0.9

November 2026 · public beta

The first public release. Everything works, and some features are brand new, so please report anything odd on GitHub Issues.

  • Live activities and drop-down banners, with Dynamic Island–style animation.
  • Music from Apple Music, Spotify, Safari, Chrome, Edge and Brave, with audio output switching.
  • Calendar countdown with one-click Join, and reminders.
  • Clipboard history, copied preview with quick actions, Files Tray and screenshot shelf.
  • Download progress for browser downloads.
  • Terminal alerts, the notch command, the local Island API, and Claude Code and GitHub Copilot CLI activity.
  • Command Bar (⌥ Space): calculate, convert units, start timers, add reminders, world time.
  • Time Machine and copy-to-drive progress, and “Safe to unplug” alerts.
  • Mic and camera indicator.
  • Home dashboard with CPU and battery history, focus timer and to-dos.
  • Colour themes, Liquid Glass, Battery saver and 7 languages.
